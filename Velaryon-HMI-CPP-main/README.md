# Velaryon - HMI for Arrax Rocket Engine

**Velaryon** is a modern and intuitive Human-Machine Interface (HMI) designed to facilitate control and monitoring for the **Arrax** student rocket engine project.

This software provides a user-friendly interface for engineers and students working on the development and testing of the **Arrax rocket engine** at the **Innovative Propulsion Laboratory (IPL)**.

> **Note:** This software is the intellectual property of **Innovative Propulsion Laboratory** and is intended for **educational and research purposes only**.

## Features
- Real-time monitoring and control of the Arrax rocket engine.
- Intuitive and modern UI for simplified interaction.
- Designed for student and research applications.

## Installation and execution

### **1. Install Qt from Qt Online Installer**
- Go to the [Qt Online Installers](https://www.qt.io/qt-educational-license#application) website.
- Apply for a Qt Educational License and follow the instruction.
- Run the executable (`.exe`, `.dmg`, or `.sh` depending on your OS).
- Follow the installation steps.
- Use your Qt account.
- Launch QT creator at the end of the installation process.

### **2. Open Velaryon in Qt Creator**
- Open the Velaryon project file (`.pro`).
- Build and run the application with the Qt kit selection (automatically selected).
> **Note:** If images are not displayed correctly, ensure that the build directory is set to the correct path. In Qt Creator, navigate to **Projects > Build & Run > General > Build directory** and verify that the directory ends with the name of the main folder containing all the files.  
> You might also need to enable the **Shadow Build** option. This allows you to modify the build directory location.
